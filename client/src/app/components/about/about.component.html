About

A Kanban board for managing tasks across three stages: To Do, In Progress, and Done. Each user has their own private board.

Getting started

  1. Register an account or sign in from the login page.
  2. Click + Add task to create your first card.
  3. Drag cards between columns as work progresses.

Working with tasks

  • Add - click + Add task, type a title, hit Save. The new card appears at the top of To Do.
  • Edit - click the pencil icon on a card to edit inline; hit Save to commit, or Cancel / Esc to discard.
  • Delete - hover a card, click ✕, then confirm in the dialog.
  • Move - drag a card to another column, or reorder it within the same column.
  • Multi-line input - the add and edit fields auto-expand as you type.

Formatting with Markdown

Card content is rendered as GitHub-flavored Markdown.

  • Headings - # Heading, ## Subheading
  • Bold / italic - **bold**, *italic*
  • Lists - - item or 1. item
  • Code - `inline` or fenced ```block```
  • Links - [label](https://example.com)
  • Quotes & rules - > quote, ---

Sub-task checklists

Use square brackets at the start of a list item to add a checkable sub-task. Click the checkbox on the rendered card to toggle it without entering edit mode.

  • - [] item or - [ ] item - unchecked
  • - [x] item - checked

Other features

  • Light and dark mode - toggle from the header; preference is saved across sessions.
  • Mobile layout - on small screens, the navigation, email, and sign-out collapse into a hamburger menu.
  • Sign out - from the header (or the hamburger menu on mobile).
  • Per-user data - each account sees only its own tasks.

Stack

  • MongoDB - document storage for tasks
  • Express.js - REST API server
  • Angular 19 - frontend framework
  • Node.js - server runtime
  • Angular CDK - drag and drop
  • marked - Markdown parsing
