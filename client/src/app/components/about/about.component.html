About

A simple Kanban board for managing tasks across three stages: To Do, In Progress, and Done. Drag and drop cards between columns to update their status, add new tasks from the board, and delete them when they're no longer needed.

Stack

  • MongoDB — document storage for tasks
  • Express.js — REST API server
  • Angular 19 — frontend framework
  • Node.js — server runtime
  • Angular CDK — drag and drop
