About

A Kanban board for managing tasks across three stages: To Do, In Progress, and Done.

Features

  • Add tasks — type in the input at the top and click Add task or press Ctrl+Enter
  • Edit tasks — hover a card and click the pencil icon to edit inline; Ctrl+Enter or click away to save, Esc to cancel
  • Markdown support — task content is rendered as Markdown; use bold, lists, code, headings, and more
  • Multi-line tasks — both the add field and the edit field expand as you type
  • Drag and drop — drag cards between columns to move them between stages, or reorder within a column
  • Delete tasks — hover a card and click ✕, then confirm in the dialog
  • Light and dark mode — toggle in the header, preference is saved across sessions

Stack

  • MongoDB — document storage for tasks
  • Express.js — REST API server
  • Angular 19 — frontend framework
  • Node.js — server runtime
  • Angular CDK — drag and drop
  • marked — Markdown parsing
